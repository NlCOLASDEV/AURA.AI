# AURA.AI — Modern AI Landing Page

AURA.AI არის თანამედროვე და responsive Landing Page, რომელიც შექმნილია თანამედროვე AI პლატფორმის კონცეფციისთვის.

პროექტის მთავარი მიზანია სუფთა, მარტივი და ვიზუალურად მიმზიდველი ვებგვერდის შექმნა, რომელიც მომხმარებელს მოკლედ აცნობს AURA.AI-ს, მის შესაძლებლობებს და აძლევს მარტივ გზას პლატფორმასთან დასაკავშირებლად.

## ✨ Features

* თანამედროვე და მინიმალისტური დიზაინი
* სრულად Responsive — Desktop, Tablet და Mobile
* Semantic HTML5 სტრუქტურა
* თანამედროვე CSS დიზაინი და ანიმაციები
* Mobile Navigation / Hamburger Menu
* Smooth Scrolling
* Scroll Reveal Animations
* Contact Form Validation
* წარმატებული ფორმის გაგზავნის შეტყობინება
* Accessibility-ის ძირითადი პრინციპები
* სუფთა და მარტივად წასაკითხი კოდი

## 📱 Responsive Design

AURA.AI ადაპტირებულია სხვადასხვა ზომის ეკრანებისთვის და მუშაობს როგორც კომპიუტერზე, ასევე ტაბლეტსა და მობილურ მოწყობილობებზე.

განსაკუთრებული ყურადღება დაეთმო მობილურ ნავიგაციას, ტექსტის ზომებს, ბარათების განლაგებას და საკონტაქტო ფორმის გამოყენებას პატარა ეკრანებზე.

## 🚀 Running the Project

პროექტის გაშვება მარტივად არის შესაძლებელი.

გახსენით `index.html` ნებისმიერ თანამედროვე ბრაუზერში.

VS Code-ის გამოყენების შემთხვევაში რეკომენდებულია **Live Server**, რათა პროექტი ლოკალურ სერვერზე გაუშვათ.

## 🎯 Project Goal

პროექტის მიზანია თანამედროვე AI პლატფორმისთვის ისეთი Landing Page-ის შექმნა, რომელიც აერთიანებს კარგ ვიზუალურ დიზაინს, responsive სტრუქტურას და მარტივ ინტერაქტიულ ფუნქციებს.

ამასთან ერთად, პროექტი აჩვენებს სემანტიკური HTML-ის, ორგანიზებული CSS-ისა და Vanilla JavaScript-ის გამოყენებას რეალურ ვებგვერდში.
